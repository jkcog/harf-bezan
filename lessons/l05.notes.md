# l05 notes

## (a) Forms I was not fully sure of
- "key" (when) and "ki" (who) are both written کی; I taught only "key" (when) and skipped "who".
- miyāy/miyād/miyāym are written with ZWNJ and a doubled ye (می‌یای) so the ZWNJ rule holds; check against l03 spelling.
- mishe is written می‌شه (ZWNJ) for consistency; common informal spelling is میشه.
- "key miri unjā?" and "kojā mikhāym berim?" are natural but word order is flexible.
- Farid answers use "voice": "farid" in a few teach/prompt steps; the English prompt text is still the learner's cue.

## (b) Teaching order
you-want -> yes/no by intonation -> āre/na -> kojā -> chi -> cherā -> key -> mishe (+ lotfan) -> he/she and we -> review of 7.

## (c) New vocabulary
kojā where, chi what, cherā why, key when, mishe can I / is it possible, lotfan please, āre yes, na no.
Plus you-forms: mikhāy, biyāy, beri, bokhori, miyāy, miri, mikhori; he/she: mikhād, biyād, bere, bokhore, miyād, mire; we: mikhāym, berim, bokhorim.
